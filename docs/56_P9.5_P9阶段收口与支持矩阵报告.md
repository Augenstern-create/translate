### 1.1 JNI LID 配置

```json
{
  "protocol_version": 1,
  "data_dir": "/data/local/tmp/p7",
  "dict_package": "/data/local/tmp/p7/p9en",
  "language_identifier": {
    "kind": "fasttext",
    "model_path": "/data/local/tmp/p7/lid.176.ftz"
  },
  "lemmatizer": "english"
}
```

- `model_path` 必须 canonicalize 后位于 `data_dir` 或 `resource_repo` 内；任意外部路径返回 `InvalidRequest`。
- 默认不加载 fastText；未编译 `fasttext` feature 时配置该字段返回 `CapabilityUnavailable`。
- `capabilities.binding` 报告 `fasttext`/`english_lemmatizer` 可用性。
- 四入口、`protocol_version=1`、错误信封不变。

### 1.2 Android 实测

- P95-A3：en→zh 样本 `light` 返回中文义项；
- 既有 P6/P8/P9.4 用例全部保持。

### 1.3 Arc 直接注入策略

- `rules_file`/`term_table_file`：自动计算文件 SHA-256，指纹 `id@version#digest`。
- 直接 `rules(Arc)`/`term_guard(Arc)`：宿主可调用 `rules_fingerprint`/`term_fingerprint` 提供摘要；
  不提供时明确只按 `id@version` 计键——**版本不变、内容变化必须由宿主改版本或提供摘要**。
- 测试：文件内容变化、直接 Arc 摘要变化均改变资源指纹。
