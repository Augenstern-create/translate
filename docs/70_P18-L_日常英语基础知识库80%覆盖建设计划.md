# 70 — P18-L 日常英语基础知识库 80% 覆盖建设计划（归档）

- 日期：2026-11-09
- 阶段：P18-L
- 前置：P17-A（报告 `docs/69`）
- 性质：计划归档；实施结果见 `docs/71`
- 核心目标：日常英语基础知识库命中率 ≥80%

## 1. 唯一核心目标

以具有代表性的日常英语知识测试集为准，使**完整知识单元**的词典命中率达到或超过
80%。80% 是知识库覆盖率，不是翻译准确率，不是 NMT 调用比例，也不是上下文选义
正确率。

不要求：80% 的完整句子由词典直接翻译；NMT 调用降至 20%；日常句子翻译准确率
达到 80%；复杂句/段落/文章质量同步提升。

## 2. 知识单元与命中口径

知识单元：一个单词、一个完整固定短语、一个常见搭配或一个常见习惯表达。

命中必须满足：

1. 通过正式启用的词典资源查询；
2. 找到完整词条/表达；
3. 至少一个非空中文释义；
4. 不依赖模型临时生成；
5. 不把“部分单词命中”或“前缀补全”算作整个短语命中。

词形回退可参与查询，但必须单独记录原形/词形命中。多义词测试项还要求返回义项
数量达到 `min_senses`。

不计入命中：部分单词、仅 NMT、学习候选池、无中文释义、查询错误、未验证候选。

主指标：

```text
命中率 = 命中知识单元数 / 测试知识单元总数 × 100%
```

## 3. 测试集规划

首批约 10,000 条：

| 类别 | 数量 |
|---|---:|
| 高频单词与常见词形 | 4,000 |
| 日常短语及动词短语 | 2,500 |
| 固定搭配 | 1,500 |
| 常见口语与日常表达 | 1,500 |
| 高频多义词 | 500 |
| **合计** | **10,000** |

按约 80/20 分建设集/冻结验收集。冻结集不得被开发脚本反复针对性补词。
数据来源必须记录名称、版本、路径、许可证与导入方式；不自动抓取版权不明确资源。

## 4. 建设顺序

1. 核验现有 ECDICT/短语资源，测量基线；
2. 高频缺失单词与义项；
3. 高频动词短语；
4. 日常固定搭配；
5. 常见口语/表达；
6. 多义词常用义项；
7. 常见词形与变体；
8. 去重、来源检查、导入、索引、资源发布；
9. 建设集/冻结集覆盖验收；
10. 工程回归。

## 5. 数据与工程约束

- 继续使用 FST + SQLite v3；不新建第二套词典存储；
- 中文释义非空、无乱码、不无故覆盖已有正确义项；
- 多义项不得随意合并；
- 来源可追溯，资源带版本与回滚；
- 不把未验证模型译文直接加入正式词库；
- 不为了凑数导入大量重复/低频/不自然表达；
- 复用 P17-A 学习链发现缺口，但默认 Off，未授权不持久化正文。
