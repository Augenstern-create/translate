## 1. 直接回答四个问题

### 1.1 日常知识库命中率是否达到 80%？

**是，但这必须带口径。**

- 定义的 10,000 条日常知识集：**10,000/10,000 = 100.00%**；
- 冻结验收集：**2,041/2,041 = 100.00%**；
- 建设前基线：**4,611/10,000 = 46.11%**；冻结集 **936/2,041 = 45.86%**。

该测试集是**源内覆盖基准**：测试单元从 ECDICT 日常候选宇宙中抽样，词典补充也
从同一来源构建。它证明“正式资源能查询到这些完整知识单元”，**不证明**独立外部
语料上的 100%，也不证明上下文选义或句子翻译准确率。外部独立基准仍待建设
（Q-077）。

### 1.2 主要增长来自哪些类别？

2. **固定搭配**：58 → 1,500；
3. **常见表达**：5 → 1,500；
4. **多义词**：499 → 500；
5. **单词**：4,000 → 4,000（原本已满）。

按覆盖率：

|---|---:|---:|
| 单词 | 100.00% | 100.00% |

### 1.3 目前还有哪些高频缺失？

- 在**已定义的 10,000 条测试集**内：建设后 **0 条**未命中；

### 2.3 过滤规则（摘要）

- 2–4 词、ASCII 小写词头，排除 `sth/sb/oneself` 等占位；
- 排除 `[网络]`、领域标记、`...`/`…`、明显技术 UI 词；
- 短语首词限常用动词；介词短语只保留白名单；
- 搭配首词限常用形容词/名词；
- 表达首词限问候/礼貌/疑问/常用主语等；
- 排除含“城镇/组织/电影/书名/人名/地名/商标”等专名提示的参考；
- 同一 unit 只保留一次。

### 4.2 单字技术补充不丢日常义项（L-07）

旧 `import_ecdict.py` 的单字 supplement 会整体替换 ECDICT 释义，导致
`stack` 只剩“栈”。P18-L 改为：

- **单字**：补充义放前面，保留原有日常义，合并去重；
- **短语**：仍整体替换，避免旧的错误短语译法继续生效。

结果示例：

- `stack`：栈；堆叠/堆/大量/书库…（≥2）；
- `bank`：银行、堤、岸；
- `light`：光、灯、轻的、淡色的、点燃等；
- `get/take/make/have/go` 均保留多义项。

验收测试 `日常多义词保留多个义项` 覆盖 bank/light/get/take/make/have/go/stack/heap/spring。

### 4.3 词形

增强 `EnglishLemmatizer`：

- 补充常见不规则动词（flew/sang/swum/wrote/spoke/broke…）；
- 补充 `-ier/-iest/-er/-est` 比较级/最高级候选与双写辅音处理。

20 个常见词形查询：**20/20 命中**，其中 **4 条**通过 lemma 回退
（happier/flew/sang/swum）。文件：`fixtures/quality/daily-word-forms-v1.txt`。

## 9. 数据质量与限制

### 已做

- 中文释义非空过滤；
- 去重（unit 唯一）；
- 过滤网络义/领域义/占位/专名提示/技术 UI 词；
- 单字 supplement 不覆盖已有义项；
- 资源版本、sha256、来源、许可证文件；
- ResourceStore 安装/回滚；
- 建设集/冻结集分离。

### 未做/风险

1. **源内基准**：测试集与补充同源，100% 不代表外部真实语料 100%（Q-077）。
2. **语义质量**：ECDICT 短语可能古旧/残片/不自然；50 条人工抽样
   `p18-dictionary-review.csv` 仍 PENDING_HUMAN（Q-079）。
3. **覆盖率≠准确率**：只证明完整词头/表达可查到中文义项，不证明上下文选对义项
   或句子翻译正确（Q-078）。
4. **词表许可**：Google 10k 未单独声明，仅本地研究选词；发行前需替换/重审
   （Q-081）。
5. **性能**：包增至 5.3 MB，word 查询约 1.4 ms/条；本阶段不做性能优化（Q-080）。

## 10. 结论

P18-L 在**明确的源内日常知识测试集**上完成了从 46.11% 到 100% 的知识库覆盖，
冻结集 100%（≥80%），并保持了 P17-A 的翻译质量与工程回归。

增长主要来自短语、搭配和表达，而不是继续堆普通单词；正式词典资源已经能由 SDK
实际查询、安装、激活和回滚。

但“达到 80%”不能外推为独立外部语料、上下文选义或翻译准确率。后续应优先：

1. 建立独立外部/人工验收集；
2. 完成 50 条（或更大）短语释义人工评审；
3. 进入 P19-G 参数化规则与上下文消歧；
4. 再按 `docs/70` §12 分别评估词典准确率、模型准确率、混合翻译准确率。
