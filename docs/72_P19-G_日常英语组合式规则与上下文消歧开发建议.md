# 72 — P19-G 日常英语组合式规则与上下文消歧开发建议（归档）

- 日期：2026-11-09
- 阶段：P19-G
- 前置：P17-A、P18-L
- 词典：`dictionary.ecdict.en-zh@0.2.0`
- 性质：计划归档；实施结果见 `docs/73`
- 核心目标：把已有词典知识转化为可复用的日常简单句翻译能力

## 1. 定位

P18-L 解决了“知识单元可查询”，P19-G 解决“简单句能否可靠组合”。不重新设计
架构，不扩大词库规模，不做通用规则 MT。

继续使用：TranslationPlanner、LanguageEvidence、DictionaryProvider、
MorphologyAnalyzer、translator-rules、Coordinator、TranslationRoute、
QualityChecker、Local/Remote 模型兜底。

## 2. 原则

1. 词典提供词义/词性/词形/短语/搭配/多义候选；
2. 语言分析提供 token、短语边界、基础词性、简单结构、否定/疑问/时态线索；
3. 规则按结构生成中文，必须完整覆盖；
4. Planner 决定 Rule 还是 NMT；
5. 不确定时回退模型，不虚假置信；
6. 规则数据化，Rust 只保留通用匹配/生成；
7. 不为每个短语写 Rust 分支；
8. 不把模型译文直接写进正式规则。

## 3. 流程

```text
输入
 → 结构分析
 → token/词形
 → 短语/固定表达优先
 → 词典义项/词性
 → 简单结构分析 + 局部选义
 → 完整规则匹配
   ├─ 可靠覆盖 → 中文组合 → 术语/质量/缓存 → 返回
   └─ 无法可靠覆盖 → LocalNMT / 已授权 Remote → 质量 → 返回
```

## 4. 范围

### G1 基础分析

- token + 原文 span；
- 词形候选（EnglishLemmatizer）；
- 名词/动词/形容词/代词/冠词/介词/助动词/情态词性；
- 短语/固定表达优先；
- 主语/谓语/宾语/否定/疑问/时间地点/条件等有限结构。

### G2 词义消歧

利用词性、动宾搭配、局部上下文、固定表达；支持唯一/多义/未知/缺词。
没有足够线索时：单词保留多义、句子回退模型。不修改原词典义项。

### G3 组合规则

首批目标句型：

- 简单陈述；
- want to；
- 礼貌祈使；
- 一般疑问；
- 特殊疑问（where）；
- 否定；
- can 能力；
- 进行时；
- 过去动作；
- be 形容词 / be afraid of；
- 有限 if 条件；
- 固定表达优先。

规则必须完整匹配；部分匹配/未知成分/复杂从句不得直接输出。

### G4 中文生成

- 基础语序（Where is my phone → 我的手机在哪里）；
- 否定（I don't like coffee → 我不喜欢咖啡）；
- 疑问语气（吗/在哪里）；
- 情态/进行/过去；
- 高频量词（a ticket → 一张票）；
- 固定表达整块处理（be afraid of、light blue）。

### G5 安全与兜底

- 所有关键成分有依据；
- 无未解释剩余 token；
- 否定/疑问/条件关系正确；
- 规则只返回匹配结果，不决定是否远程；
- 远程授权语义不变。

## 5. 验收矩阵

| ID | 项目 | 要求 |
|---|---|---|
| G-01 | 分词与跨度 | 原文定位正确 |
| G-02 | 词形 | 常见变形可还原 |
| G-03 | 词性 | 基础句型词性有效 |
| G-04 | 完整短语 | 优先于拆词 |
| G-05 | 多义消歧 | 明确语境选对 |
| G-06 | 歧义回退 | 不强行选义 |
| G-07 | 参数化规则 | 可处理未硬编码新句 |
| G-08 | 完整覆盖 | 部分匹配不输出 |
| G-09 | 中文生成 | 语序/否定正确 |
| G-10 | 模型兜底 | 复杂输入进 NMT |
| G-11 | 缓存/资源 | 规则版本隔离 |
| G-12 | API 兼容 | 既有行为不回退 |
| G-13 | 段落/文档 | 结构与轨迹正常 |
| G-14 | 工程质量 | tests/fmt/clippy |

## 6. 不做

大规模词库扩张、复杂句完整语法、大型 NLP 框架、NMT 替换/训练、fp32 默认、
收费远程 API、Android 新 NMT、ncnn、Fast 流式、DOCX/PDF、外部 CI、发行准备。

## 7. 权限

工作区、Python、Android 模拟器、工作区外操作、上传、付费 API、资源许可证等
边界与 P17-A/P18-L 相同；G11/G12 保持 open。
