## 0. 目标与原则

P9 在 P0～P8 基础上补齐：真实 en→zh 词典、Kaikki JSONL、JMdict XML、正式 LID、英语 lemmatizer、
日语形态分析、跨平台集成、P8 遗留 EP-02（规则/术语内容摘要）。

原则：先审核源码/资源再开发；复用 `DictionaryProvider` + FST/SQLite v2；不改 JNI v1 ABI；
资源可选安装；默认离线；低内存；LID/分词/形态均为可选插件；来源/版本/哈希/许可可追溯；开发与发行分离；
G11/G12 保持 open。

## 3. P9.0 准入

候选：CC-CEDICT（保留）、Kaikki/Wiktionary JSONL、JMdict XML、fastText `lid.176.ftz`、Lindera/IPADIC/UniDic。

要求：官方来源、格式、revision、SHA-256、许可证/署名/加工/再分发/内部研究/公开仓库/低内存适配逐项记录；
未取得数据允许 null，不得填猜测哈希；未获批准不下载大源、不分发。

锁文件建议字段：`source_id/source_revision/source_format/source_sha256/license/redistribution_status/converter_version/language_pair`。

## 4. P9.1 词典

统一链路：CC-CEDICT / Kaikki / JMdict → NormalizedEntry → 校验 → FST + SQLite v2 → Manifest+SHA-256 → Resource Store → DictionaryProvider → `Translator.lookup`。

- **en→zh P0**：禁止把 CC-CEDICT 英文释义倒排冒充完整 en→zh；需真实英语词头 + 中文释义关系；质量样本 bank/spring/charge/light/run/match/right/book/close/present，检查词性/义项/来源。
- **Kaikki**：streaming JSONL；处理坏 JSON/缺 word/缺 language/空 senses/多 gloss/forms/alt spelling/多 POS/translation 字段/缺 source id/非目标语言/超长/重复；输出真实导入统计。
- **JMdict**：保留 ent_seq/k_ele/r_ele/sense/POS/gloss/词形读音限制/来源；样本 食べる/学校/行く/今日/はし；汉字+假名检索；同音词不压成无来源单条。
- 测试：DI-01～DI-08；每语言对目标 100 条人工样本；导入成功≠质量合格。

## 5. P9.2 LID

保留 `HeuristicIdentifier`，新增可选 `FastTextIdentifier`；优先审计现有 `LanguageIdentifier` 注入点。
显式 source 优先；未指定才识别；模型可用优先模型，否则 fallback；短文本/混合语言多候选；低置信不触发远程；
缺 LID 不阻断显式语言；模型身份进诊断。
指标：Accuracy/Macro F1/逐语言 P/R/混淆矩阵/短文本/混合候选/加载时延/热 p50/p95/体积/RSS。
测试 LID-01～LID-07；不得未测先宣称 fastText 更优。

## 6. P9.3 形态

可选 `MorphologyAnalyzer` → lemma/reading/POS → DictionaryProvider.lookup；不改原文/URL/代码/占位符；不把形态当 NMT。

- 英语：轻量规则+例外词表；样本 running/walked/children/mice/went/studies/better；避免粗暴去 s/名词动词合并/覆盖原文。
- 日语：Lindera 可选 PoC；确认版本/词典/许可/体积/RSS/Android x86_64/无词典降级；样本 食べました/行きます/学校へ行く/大きかった/たべる。
- 测试 MOR-01～MOR-05。

## 7. P9.4 集成

Java/Kotlin → JNI v1 四入口 → Translator API → LID/Morphology/DictionaryProvider → Resource Store；
新能力走 `nativeCall` 扩展并明确 DTO 版本/旧宿主兼容/未知 method/多实例/资源卸载/JSON 安全上限。
Android 仅 x86_64 AVD；验证英→中、日→英、Unicode、双实例不同包、关 A 不影响 B、缺资源错误、重复加载/卸载、
LID 可用/不可用、形态不改文本、RSS/p50/p95；ARM64 仅交叉编译则标未验证。
Linux/Windows 跑 fmt/clippy/test/all-features；Windows 沿用工作区隔离配置；`--release-mode` 在 G11/G12 open 时预期 FAIL。

## 8. P8 遗留

- **EP-02**：规则/术语文件内容 SHA-256、资源激活快照身份、Coordinator CacheKey、内容变化失效合同；EP-02a～e。
- **EP-04**：自定义隐私域留 P11，与 Remote Provider/多宿主缓存一起评审，不在词典阶段改公共 API。
