# 76 — P21-R 中文生成体系深化与规则统一计划（归档）

- 日期：2026-11-09
- 阶段：P21-R
- 前置：P17-A、P18-L、P19-G、P20-C
- 性质：计划归档；实施结果见 `docs/77`
- 范围：English → Simplified Chinese，以 Sentence 为主
- 优先级：语义准确性 > 中文自然度 > 泛化 > 覆盖率 > 性能

## 1. 目标

把 P19 的整句型规则、P20 的局部语义帧统一到：

```text
Token/Span
 → Lexical & Syntactic Analysis
 → MeaningFrame / MeaningProgram
 → Transfer
 → ChineseRealizer
 → Candidate Validation / Selection
 → Coordinator Rule / Fallback
```

不新建 Planner/Translator/资源系统；P19 保留为稳定兼容路径和 A/B 基线。

## 2. 原则

1. 英语分析与中文生成分离；
2. 语义表示尽量独立于表面字符串；
3. 词义、搭配、结构和中文生成规则可复用；
4. 局部候选允许，但最终必须保留必要语义；
5. 一个语义结构可产生多个中文候选；
6. 不确定时安全回退；
7. 不以 chrF 或流畅度分数单独证明语义/自然度；
8. 默认行为必须由独立测试和人工评审决定。

## 3. 不做什么

- 不扩大整句硬编码模板；
- 不做通用英语语法解析器；
- 不一次性支持全部从句/时态/指代；
- 不重设 Planner/Coordinator；
- 不建平行资源系统；
- 不把语言模型概率等同自然度；
- 不引进大型中文 LM 作为前置依赖。

## 5. 首批迁移句型

简单主谓宾、礼貌祈使、一般疑问、where、want-to、can、进行时、过去动作、
be 形容词、常见否定。固定表达可保留原子化路径。

## 6. 中文生成要求

- NP：单复数、数量、量词、形容词、领属、指示、简单多层定语；
- 语序：主谓宾、时间/地点、程度、简单并列；
- 否定：不/没/不能/不会，作用域正确；
- 体貌：了/过/着/正在/无标记，不能按英语时态机械映射；
- 助词：的/地/得按结构生成，不用英语 POS 直接决定；
- 候选：`RealizationCandidate` + 语义硬约束 + 结构合法性 + 确定性排序。

## 7. 测试与验收

- 旧 P19 36/5、P20 4/3 保持；
- P21 中文专项：NP/量词、语序、否定、体貌、修饰、并列、多义词、拒绝；
- 词汇替换/结构变化，不仅测规则原句；
- 320 不出现无解释整体退化；
- 文档结构 1.0；
- 默认/全特性测试、fmt、clippy；
- 人工盲评 PENDING_HUMAN 未完成不得写 PASS。
