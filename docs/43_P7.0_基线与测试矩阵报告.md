## 3. 与原设计的偏差及原因

- **D-144：P7.0 不改任何代码、不跑 Android 测试。**
  原因：`docs/42` 把 P7.0 定义为"冻结基线 + 只读预检 + 测试矩阵"。影响：P7.1 才是第一段真正写测试的阶段；
  本轮没有新增"通过"结论。
- **D-145：阻断项定义与旧报告不一致，按台账纠偏。**
  台账原文：G06 = 不支持取消在途请求、G08 = 恢复测试用 `abort()` 而非外部 `kill -9`、D-46 = 许可证正文未入库。
  这与 `docs/25`/`docs/34` 里的措辞不同（后者已被 `docs/27` R-01 纠过一次）。
  影响：**P7.4 必须逐条按此表取证**；其中 D-46 只是补两个 LICENSE 文件，G06 才是真正的功能缺口。
- **D-146：J-15c（`.so` 重载）直接标 PENDING 而非尝试。**
  原因：ART 不提供可靠的 `System.loadLibrary` 卸载语义，强行测只能得到"看起来失败/看起来成功"的假结论。
  影响：报告里必须写明这是**类加载器限制**，不是 SDK 缺陷。
- **D-147：Linux 侧 `target/` 与 `~/Android/Sdk` 已有目录本轮按既有授权处理，未新增路径。**
  若 P7.1/P7.2 需要新的工作区外写入（如迁移 AVD 缓存），我会先申请。
