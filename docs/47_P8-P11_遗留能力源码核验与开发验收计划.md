## 2. P8 — 多实例、共享资源与缓存一致性

| 工作包 | 核心要求 | 测试 |
|---|---|---|
| **P8.1 JNI 多实例（P0）** | handle 仍 `"gen:index"`；每个 Entry 自己的 generation/closed；index 不复用；close A 只关 A；`capabilities.binding.multi_instance=true` 通过后启用 | M-01 双实例共存；M-02 交替调用不串；M-03 关 A 不影响 B；M-04 关 A 建 C，A 不复活；M-05 8 线程 create/call/close；M-06 伪造 handle 受控拒绝 |
| **P8.2 共享模型/worker** | 按 `(runtime, model digest, tokenizer, precision, device, decoding)` 标识缓存槽；区分不可变权重共享与推理会话隔离；引用计数/TTL/失败状态 | SM-01 同 digest 初始化=1；SM-02 关 A B 仍可用；SM-03 最后实例释放后可卸载；SM-04 不同 digest 不误共享；SM-05 取消/崩溃/并发 shutdown 无僵死；SM-06 预算不足 `OutOfBudget` 且 host+worker 内存都记 |
| **P8.3 执行计划/缓存** | 计划含 engine/runtime/build/model+tokenizer digest/语言/decoding/rules/terms/privacy；canonical 哈希；不混绝对路径/密钥/原文 | EP-01 同 id@version 不同权重不复用；EP-02 规则/术语/词典变化失效；EP-03 beam/语言/backend/路径变化不串；EP-04 隐私域隔离；EP-05 取消/失败/严格还原失败不写成功缓存；EP-06 v1/v2 与热切换快照 |

**P8 出口门**：P8.1～P8.3 完成或有明确 Verified/Deferred 判定；核心 API 不依赖具体 runtime；Android 模拟器多实例合同通过；全量测试与 `-D warnings` 通过。

## 7. DoD / 质量门

每工作包：先核验当前 commit/源码/测试/差异；写判定；公共 API/JNI v1 不破坏；新增合同 + P0～P7 回归；性能有脚本/基线/口径；安全隐私默认无外网、许可可追溯；权限审计；报告三段式（实现/测试/偏差）+ pending。

停止条件：工作区外未批写入；依赖/模型侵权或收费调用未批；真实 NMT 与 Mock 无法区分；原生崩溃穿越隔离/数据损坏/取消孤儿；ARM64 仅交叉编译却冒充运行；基线回退且无法解释。

## 8. 范围外

不正式发版、不 push GitHub/外部 CI；不做 Android 真机/物理性能；不做 GUI/APK 正式生命周期/动态插件市场；不训练大模型；不默认装全量词库；不删旧 ORT/AVD；G12 不因本计划关闭。
