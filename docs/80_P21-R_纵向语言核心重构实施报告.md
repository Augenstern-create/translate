修改前（简单句仍可走旧链）：

```text

```

修改后（已迁移简单陈述/否定/时间/进行/情态/被动/want/条件结构优先）：


## 2. 首个纵向样本

输入：

```text
She didn't buy two new books yesterday.
```

实际中间结构：

- TokenStream：`she / did / not / buy / two / new / books / yesterday`；
  contraction 派生 token 保留源 span；数字/未知片段会令 `coverage.complete=false`。
- SyntaxGraph：
  - Clause → Subject(NounPhrase she)
  - Clause → Predicate(VerbPhrase buy)
  - Predicate → Negation(not)
  - Predicate → Object(NounPhrase book)
  - Object → Quantity(2)
  - Object → Modifier(new)
  - Predicate → Adverbial(yesterday)
- MeaningGraph：
  - Event BUY
  - Agent SHE
  - Patient BOOK
  - Quantity(BOOK, 2)
  - Modifier(BOOK, new)
  - Time(BUY, yesterday)
  - Scope(Negation → BUY)
  - `tense_past = true`
- ChineseSyntaxTree：
  - Clause
    - Subject NP 她
    - Time 昨天
    - Negation 没
    - Verb 买
    - Object NP: Quantity 两 + Classifier 本 + Modifier 新 + Noun 书
- Validation：按目标节点类型映射 Meaning nodes，缺失 Verb/Noun/Quantity/Modifier/Time/Negation 则拒绝。
- 输出：`她昨天没买两本新书。`

测试：`crates/translator-api/tests/p80_pipeline.rs`。

## 4. 覆盖与词义

- `tokenize_lossless` 保留 Number/Symbol/Unknown；有 Unresolved 时 pipeline 不接管。
- `She bought two books 20.` / `She bought 2 books.` 返回 NMT，不静默删除。
- `MeaningGraph` 使用 `SenseResolution::{Resolved,Ambiguous,Unresolved}`。
- 未解析/多义 sense 时 pipeline 返回 None。
- `senses` 数据表支持同 POS 按 object 选择（run/company、take/photo）。
