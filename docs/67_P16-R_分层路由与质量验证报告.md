## 1. 三层路由

新增公开类型：

```rust
pub enum TranslationRoute { Dictionary, Rule, LocalNmt, Mixed }
pub struct RouteStats {
    executions, dictionary_hits, rule_matches,
    nmt_calls, nmt_fallbacks, cache_hits,
    best_candidates, failures
}
```

- `TranslationDiagnostics` 增加 `route`、`model_invoked`、`dictionary_hit`、`rule_matched`。
- `CacheKey` 增加 `route`；词典/规则/NMT 结果不得互相复用。
- `Translator::route_stats()` / `reset_route_stats()`；quality-runner 每条输出与 summary 都带路由字段和统计。

## 4. R3 — 复杂句与 NMT

- 复杂句测试（否定+因果）仍进入真实 NMT，`route=LocalNmt`、`model_invoked=true`、`nmt_calls=1`。
- NMT 路径继续执行数字/占位符/URL/术语/结构恢复/quality check。
- 320 句对照（text_kind=Sentence，同一模型/配置）：

| 配置 | chrF | BLEU | NMT 调用 | 规则命中 | fatal |
|---|---:|---:|---:|---:|---:|
| 无模板（P12 full） | 0.4703 | 0.4641 | **322** | 0 | 0 |
| + 40 条模板（P16） | **0.5074** | **0.5060** | **300** | **22** | 0 |

- **NMT 减少 22 次（−6.8%）**；
- **chrF +0.0371 / BLEU +0.0419**；
- **0 条回归、20 条改善**；数字保真 1.0；占位符 1.0。

> 22 条模板命中换来 22 条规则路由，所以 NMT 322→300；320 + 2 条分句执行单元 = 322 executions，与统计口径一致。

## 6. R5 — 缓存、诊断与统计

- `CacheKey.route`：Dictionary/Rule/LocalNmt 不共享；测试 `不同路由不得共享缓存`。
- 模板结果与 NMT 结果不共享（`规则与模型结果不共享缓存`）。
- `RouteStats` 区分：
  - logical executions（含段落/文章单元）；
  - dictionary_hits；
  - rule_matches；
  - nmt_calls（真实推理）；
  - nmt_fallbacks；
  - cache_hits；
  - best_candidates（Best 生成两个候选）；
  - failures。
- `executions` 是执行单元数，不等于宿主逻辑请求数；段落/文章会按单元计数（已在报告中说明）。

## 7. 兼容性与模式

- 默认 Precise；Fast 显式选择；旧 `TranslateRequest` 不变；
- JNI v1 四入口不变；
- Fast 走同一路由，不绕过数字/占位符/关键完整性检查；
- 词典/模板失败不会静默退化：模板加载失败计入构建错误；词典 miss 才 NMT。
