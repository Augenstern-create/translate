## 1. P9.2 fastText LID

### 1.1 实现

- 新增可选 feature `translator-analysis/fasttext`，依赖 **`fasttext-pure-rs 0.1.0`**（MIT，纯 Rust，无 native 构建脚本）。
- `FastTextIdentifier` 实现现有 `LanguageIdentifier`：
  - `from_path` / `from_bytes` 显式加载 `lid.176.ftz`；不自动下载、不写缓存；
  - 标签 `__label__eng` / `cmn` / `jpn` / `kor` / `zh` / `wuu` / `yue` 等映射到项目标签；
  - 未知 2/3 字母标签保留，不伪造。
- 模型由宿主提供；本仓库不提交权重/模型。

依赖审查：`fasttext-pure-rs` 为 MIT、纯 Rust、无 build.rs/native；`license-audit.py --check` 更新为 **173 包**（原 172）。
它声明 `rust-version=1.89`，高于 workspace 的 1.80；因此只作为**可选 feature**，默认构建不引入。

### 1.2 同集对照（40 条，en/zh/ja/ko 各 10）

```bash

cargo test -p translator-analysis --features fasttext --test p9_lid_compare -- --ignored --nocapture
```

说明：

- 40 条是**工程对照集**，不是 LID-02 的正式混淆矩阵；准确率相同不代表所有语言/短文本等价。
- 中日共用汉字仍是主要混淆源；fastText 将“漢字”判为 ja，启发式判为 zh-Hans。
- 模型 drop 后 RSS 未完全回到加载前（allocator 保留），不能宣称“卸载即归还全部 RSS”。
- 本 PoC **尚未接入** `Translator::detect_language` / 路由；现有 API 没有 LID 注入点，P9.4 再接入。

证据：`tests/p9/lid-compare.json`。

## 2. P9.3-A 英语轻量 lemmatizer

### 2.1 实现

- `translator-analysis::EnglishLemmatizer` + `MorphologyAnalyzer` trait；纯规则 + 高频例外词表，无模型/大词典。
- 只返回**候选 lemma**，不修改原文；调用方应把候选交给词典查询。
- 规则覆盖：`ies→y`、`ves→f/fe`、`es`、`s`（排除 ss/us/is）、`ing/ed`（含去 e、双写辅音）。
- 例外：went→go、children→child、mice→mouse、better→good、was/were→be、has/had→have、did/done→do、saw/seen→see 等。

### 2.2 测试

`cargo test -p translator-analysis --features fasttext --lib` → **8 passed**（包含 1 条 lemmatizer 用例覆盖 9 个规则/不规则词 + glass/bus 反例）。

样本结果：

| 输入 | 候选包含 |
|---|---|
| running | run |
| walked | walk |
| children | child |
| mice | mouse |
| went | go |
| studies | study |
| boxes | box |
| making | make |
| stopped | stop |
| better | good |

**边界**：尚未把 lemmatizer 接到 `DictionaryProvider.lookup`；P9.4 做查询候选集成并验证不改 `ProtectedSpan`。
