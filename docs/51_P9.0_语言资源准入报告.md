## 4. 许可证问题清单（需用户/法务决策）

1. **CC-CEDICT**：现有包内是 CC BY-SA 4.0；对外分发时的署名、ShareAlike 适用范围、修改标注方式需要确认。当前只做本地/内部使用。
2. **Kaikki / Wiktionary**：不同语言版本、不同来源条目的许可证可能不同；必须固定具体 dump/revision，并保留 attribution/SA 义务。不能只看 Kaikki 网站首页。
3. **JMdict / EDRDG**：以 EDRDG 官方当前条款为准；需要署名与再分发说明；不能只依赖 crate SPDX。
4. **fastText**：代码许可证与模型文件许可证分开确认；模型下载来源、哈希、体积需实测。
5. **Lindera**：Rust crate 与 IPADIC/UniDic 词典数据分别审核；词典可能比 crate 许可更严格。
6. **en→zh 数据**：不能把 CC-CEDICT 英文释义倒排；需选择真实英语词头 + 中文释义的数据（可能来自中文 Wiktionary/Kaikki 提取），并单独审查其质量与许可。
