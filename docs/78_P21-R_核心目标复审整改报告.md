## 3. 本轮修复的关键问题

### 3.1 搭配不能丢修饰语

`He runs a small company.` 曾被数据化搭配输出为“他经营一家公司”，丢失 `small`。
现改为：

```text
collocation = 目标动词（经营）
object      = 统一 NP（一家小公司）
结果        = 他经营一家小公司。
```

搭配数据只提供动词，不提供整句或完整宾语；NP 仍由共享 `entity_zh` 生成，
因此形容词、数量、指代不会被搭配表覆盖。

### 3.2 候选验证不能只看“有否定词”

`He didn't go.` 的错误候选 `他不想去。` 同时含“不”，旧检查会通过。
现按 frame 判定：

- Past → 必须含 `没`
- Simple → 必须含 `不`
- Modal → 必须含 `不会`
- Progressive → 必须含 `没在`
- have + negative → 必须含 `没有`

该反例已加入测试，要求 `wrong-negation`。

### 3.3 have 否定

`He doesn't have a computer.` 从错误“他不有一台电脑”修为“他没有一台电脑。”，
并加入 20 条后置集。

## 5. 仍不能宣称完成

本轮补强的是**结构覆盖、数据化搭配、候选否定验证和测试规模**，不是完整语义理解：

- 复杂从句/PP/相对从句仍未覆盖；
- 条件、比较、被动、复杂从句、PP 附着、长距离指代仍缺；
- “的/地/得”、过/着、复杂补语仍不完整；
- WSD 仍是数据化搭配 + 句法角色，不是完整 sense 候选/论元语义分类；
- 100 矩阵是开发/回归集，20 后置集也非完全未触达；
- 98 行人工评审全部 `PENDING_HUMAN`；
- 语义路径仍 opt-in，未默认切换。

因此 P21-R 继续保持 **PARTIAL / 不关闭**，不以工程全绿或矩阵 100/100 代替核心目标验收。
