# 74 — P20-C 语义驱动组合翻译与中文生成核心计划（归档）

- 日期：2026-11-09
- 阶段：P20-C
- 前置：P17-A、P18-L、P19-G
- 性质：计划归档；实施结果见 `docs/75`
- 范围：English → Simplified Chinese，先聚焦 Sentence
- 优先级：准确性/语义完整性/中文自然度 > 规则覆盖率 > 性能

## 1. 目标

从 P19-G 的整句匹配推进到可复用链路：

```text
token/span
 → 局部词汇与句法候选
 → MeaningFrame（谓词/论元/极性/情态/时体/疑问/条件）
 → 英中结构转换
 → ChineseRealizer（多候选）
 → 硬约束/结构/候选校验
 → 统一 Coordinator
```

不建新 Planner/Translator/资源系统；新能力在 P19-G Composition 内部或旁侧增量化。
P19-G 稳定整句路径保留，作为 A/B 基线。

## 2. 原则

1. 局部候选可以产生，但最终不能丢必要源文信息；
2. 语义关系优先于字符串拼接；
3. ChineseRealizer 独立成层，支持语序/量词/虚词/否定/疑问/体貌/搭配；
4. 不确定时拒绝组合，继续 Local NMT / 已授权 Remote；
5. 不以新增句型数、匹配数或中文流畅度模型分数替代语义正确性；
6. 不为 P20-C 新建独立 API/缓存/资源系统；
7. 不默认下载大型 NLP 框架；依赖和许可证先核验。

## 3. 模块边界

| 模块 | 责任 | 禁止 |
|---|---|---|
| LexicalAnalyzer/词典 | 词形、POS、词义、短语证据 | 决定整句译文 |
| CompositionAnalyzer | 带 span 的局部结构候选 | 静默丢弃未识别部分 |
| MeaningFrame | 谓词、论元、作用域、修饰、时体、疑问、条件 | 硬编码中文表面字符串 |
| Transfer | 源语义/词义到目标词汇/结构 | 无根据猜歧义 |
| ChineseRealizer | 中文语序、量词、助词、否定、疑问、体貌 | 以流畅度改语义 |
| CandidateSelector | 硬约束/覆盖/安全候选 | 自行决定 Remote |
| Planner/Coordinator | 最终路由、术语、质量、缓存、Trace | 复制语义栈 |

## 4. 两种覆盖

- 词法覆盖：源 token/span 是否被候选处理；标点/格式单独记账。
- 语义覆盖：否定、条件、疑问、宾语、修饰、数量、时间、指代是否保持。

词法 100% 不是语义完整的证明。不能把局部中文片段直接串成最终译文。

## 5. 第一批结构

- 名词短语（限定词/数量/量词/形容词）；
- 简单动词短语；
- 礼貌祈使；
- 简单主谓宾；
- 并列独立分句；
- 明确时间/地点状语；
- 固定表达优先（light blue、turn off、be afraid of）。

嵌套从句、否定范围不明、介词附着歧义、长距离指代、复杂条件/多层从句：
保存分析证据后整句回退 NMT。

## 6. 实施顺序

- C0 冻结 P19-G 36 正例/5 反例、320、10 文档、默认/全特性；
- C1 局部候选 + MeaningFrame + 拒绝原因 + Trace；
- C2 ChineseRealizer 最小版：语序/名词短语/量词/否定/疑问/体貌/固定搭配/并列；
- C3 部分匹配组合与安全回退；
- C4 P19 vs 新 Realizer vs 局部组合 A/B。

## 7. 评测

必须同时保留旧集不退化与新能力独立集有效；记录：

- 正例/反例；
- 多合法译法；
- Partial Coverage / Safe Composition / Unsafe Acceptance；
- 320/文档 chrF/BLEU、Route、NMT 调用；
- 人工语义/信息/自然度三维评分；
- Trace：候选、语义关系、生成规则、拒绝理由、最终路由。

### 初始对抗例

| 源文 | 考点 | 期待 |
|---|---|---|
| Please open the door and close the window. | 并列祈使 | 可组合无遗漏 |
| I don't want to go. | 否定范围 | 不得机械拼“想不去” |
| The light blue bag is heavy. | 固定颜色短语 | light blue 不拆 |
| She bought a new phone yesterday. | 时间/量词 | 多合法语序 |
| If the server fails, restart it. | 条件/指代 | 未解决指代则回退 |
| I saw the man with a telescope. | PP 附着歧义 | 不臆定修饰 |
| He didn't say she stole it. | 嵌套否定 | 无作用域证据则回退 |
