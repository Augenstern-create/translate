## 2. JMdict 同音词多值索引（v3）

### 2.1 设计

保持 FST + SQLite 架构；新增 payload `dictionary.sqlite.v3`：

```text
FST key "はし" -> first entry_id（只用于存在性）
SQLite postings(key TEXT, rank INTEGER, entry_id INTEGER)
    -> 橋 / 箸 / 端 / 梯 / 愛し / 波斯
```

- `payload_schema_version=dictionary.sqlite.v3`；`PRAGMA user_version=3`。
- 旧 v1/v2 包**完全兼容**：`lookup_exact` 仍走单值；新 `lookup_exact_all` 对 v1/v2 返回 0/1 条。
- `DictionaryProvider::lookup` 改用 `lookup_exact_all`；`DictionaryEngine::translate` 仍取首条（精确词条直译）。
- 排序由 `postings.rank` 固定；重复 `entry_id` 不会重复返回。
- 资源层 `PayloadSchema` 增加 v3；旧资源不受影响。

### 2.2 实测（JMdict v3 包）

`lookup はし --limit 100` 返回 **6 条**，各自独立：

| # | 词头 | 首义 |
|---|---|---|
| 1 | 橋 | bridge |
| 2 | 箸 | chopsticks |
| 3 | 端 | end (e.g. of street) |
| 4 | 梯 | ladder |
| 5 | 愛し | lovely |
| 6 | 波斯 | Persia |

`橋`/`箸`/`端` 单独查询各自只返回本词义，不再混在一起。
