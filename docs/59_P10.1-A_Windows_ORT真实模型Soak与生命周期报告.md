## 2. A1 冷/热基线

| 指标 | 值 |
|---|---:|
| 冷加载 | **704.4 ms** |
| 热 p50 | **185.76 ms** |
| 热 p95 | **651.08 ms** |
| 1,000 次错误 | **0** |
| 加载后 RSS / Private | 287.4 / 275.0 |
| 1,000 次后 RSS / Private | 424.7 / 413.1 |
| 卸载后 RSS / Private | 34.9 / 20.2 |
| 池释放后 RSS / Private | 37.3 / 22.1 |

结论：ORT 加载后 +278 MiB、推理稳态 +137 MiB；卸载后 Private Bytes 从 413 降到 20 MiB，说明会话/arena 释放；
RSS 未回到 9 MiB 属 allocator/共享页保留，不能要求归零。

## 3. A2 1,000 次 Soak

- 调用 1,000 次，错误 **0**；
- 第 500 / 1,000 次采样均为 RSS 424.7 / Private 413.1 MiB，**无持续增长**；
- `shared_arc=true`、`shared_pool_count=1`：两个实例确实复用同一 ORT 引擎；
- 卸载后 B 重新翻译成功（`b_reload_ok=true`，2,139 ms），说明共享会话在 unload 后可重建；
- 原始 JSON/日志：`tests/p10/ort-1000.json`、`ort-1000.log`。

## 5. A4 共享与故障生命周期

| ID | 场景 | 结果 |
|---|---|---|
| NM-06 | 两实例共享 ORT 会话 | **PASS**：`Arc::ptr_eq=true`、pool=1；共享重建成功 |
| NM-07 | 取消 | **N/A**：ORT 后端没有请求级取消点，`timeout_ms` 接受但不生效（P4 已记录）；不得用强杀进程模拟 |
| NM-08 | 在飞卸载 | **PASS（既有合同）**：`p4_contract` 的 in-flight unload 用例在 Windows ORT 通过；无 UAF/死锁 |
| NM-10 | 模型内容变化 | **PENDING**：未替换真实模型文件做共享池/缓存身份实验 |
| NM-11 | 内存预算 | **PARTIAL**：预算为下界估计，不能把 424 MiB 实测直接当预算；本轮只记录实际值 |
| NM-12 | 最后实例释放 | **PASS（趋势）**：drop 后 Private 22 MiB；P8 Weak 合同另有测试 |

**共享故障语义**（与 P8 文档一致）：共享引擎/会话是共享故障域；ORT 无请求级取消，不能把“宿主不再等待”当成
底层停止。A 的 unload 会影响共享 B，但 B 可重新加载；不许静默重试。
